# Learning Journal

## Purpose and Honesty Rule

This records learner practice and questions, separately from software delivery.
An assistant can prepare a lesson and pass tests; it cannot infer that the
learner understands it. Initial status for every concept is **not assessed**.
Self-reported confidence is useful but is distinct from demonstrated behavior.

explained independently, applied independently. These are observations about a
specific exercise, not permanent judgments about ability.

## Error Notebook

For each useful mistake, record the symptom, initial hypothesis, evidence,
actual cause, correction, and a test that distinguishes this cause from another.
This makes debugging knowledge reusable instead of recording only the final fix.
